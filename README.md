# 🚀 Startup Incubation Center – Landing Page

A sleek and responsive landing page built in just 3 hours during a web-athon, showcasing the vision and offerings of a Startup Incubation Center. Designed to attract aspiring entrepreneurs and provide essential information at a glance.

## 🌟 Key Features
- 📱 Fully responsive design
- 🧭 Clean navigation and section layout
- 💼 Overview of services for startups
- 📍 Contact / Location / Social links
- 🖼️ Hero banner with call-to-action

## 🛠️ Tech Stack
- ReactJs
- Tailwind CSS
